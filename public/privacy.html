Privacy Policy

Last updated: September 20, 2026

1. Overview

Timeline is a personal timeline tool that allows users to save dates, events, categories, and time periods. This Privacy Policy explains what information Timeline stores and how it is used.

2. Information We Store

When you create an event, Timeline may store information including the event title, category, start date, end date, selected color, and other settings associated with the event.

3. Database Storage

Timeline currently uses a cloud-hosted PostgreSQL database provided by Neon to store timeline event information.

4. Local Browser Storage

Timeline may use your browser's local storage to remember interface preferences such as dark or light mode and the selected interface accent color.

5. How Information Is Used

Information stored by Timeline is used to display, organize, edit, calculate, and manage timeline events.

6. Data Deletion

Events can be removed using the delete feature available within Timeline. Once an event is deleted, it is removed from the application's active event database.

7. Sensitive Information

Users should avoid entering passwords, financial account details, government identification numbers, medical records, or other highly sensitive information into Timeline.

8. Changes to This Policy

This Privacy Policy may be updated when Timeline adds new features or changes how information is stored or processed.

9. Contact

Contact information may be added here if Timeline becomes publicly available to other users.
